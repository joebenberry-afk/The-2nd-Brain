# Context economics and integration negative control

An isolated probe created one VERIFIED semantic memory, confirmed that the
public semantic search found it, then compiled the current JIT capsule for the
same task. The memory ID was absent from the capsule. At 55% reported context
usage, the monitor returned pressure strength `1` even though the declared
configuration says green through 60%; the monitor still uses hard-coded 50/80
boundaries.

Therefore the completion-reserve experiment cannot be labeled C3 ACTIVE yet:
there is no official Prime injection path, no Brain token measurement, and no
reserve enforcement in the current integration. The result is evidence for
the Phase 0 F-02/F-05 scope decision, not a memory-efficacy result.
