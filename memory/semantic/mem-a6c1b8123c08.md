OMP 18.1.15 documented integration: text/JSON/RPC/RPC-UI/ACP modes, Bun SDK, extension tools/commands/events/providers, and MCP tools/resources/prompts over stdio/HTTP/SSE. RPC acknowledgements are not terminal agent completion; correlated responses and event subscriptions must be handled separately. Extensions execute in-process without sandbox isolation. Typed hook declarations do not prove every host emits the event, and UI APIs depend on the mode. These native surfaces are distinct from Second Brain implementation and qualification evidence.
