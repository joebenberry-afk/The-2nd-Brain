OMP 18.1.15 native memory: settings schema and memory.md support five memory.backend values: off, local, hindsight, mnemopi and sharpshooter. Shorter README/settings overview lists are incomplete. Native memory defaults to off and was observed off in this repository/profile on 2026-09-11. Native local summaries, remote Hindsight, SQLite Mnemopi and Sharpshooter are distinct from Second Brain. Scoping, model routing and maintenance vary by backend; do not apply one backend policy universally or enable another memory system automatically.
