Gotcha (Claude Code 2.1.292, 9 Oct 2026): permission rule Skill(anthropic-skills:deep-research) in permissions.deny also blocks the plugin skill deep-research:deep-research ('Skill execution blocked by permission rules') - matching is by skill name, so a deny rule cannot pick between two same-named skills. Rename one or turn the synced one off on claude.ai.
