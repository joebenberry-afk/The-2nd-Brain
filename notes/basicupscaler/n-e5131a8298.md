Owner's laptop panel was running at 60 Hz on AC (28 Sep 2026): EnumDisplaySettings offers only 30/48/60 Hz at 1920x1200, G-Helper config screen_max=60, screen_auto=1, gpu_mode=2. WGC capture happens at DWM composition, so BasicUpscaler's capture delay is up to one refresh (16.7 ms at 60 Hz) with a random per-session phase (2–18 ms p50 across runs; low-delay runs skip frames). Always check refresh rate before latency conclusions. Also: WGC frame SystemRelativeTime is ~15 ms AFTER FrameArrived on this system (a target display time), not the capture moment.
