Vulkan loader (loader.c 1285, checked 23 Oct 2026): an implicit layer's disable_environment disables if the variable is set to ANY value (only existence is checked); enable_environment needs an exact value match. VK_ADD_IMPLICIT_LAYER_PATH is ignored for elevated processes. vkEnumerateInstanceLayerProperties lists every parsed implicit layer whether enabled or not (loader.c 7261-7300), so 'listed but DLL not in process' proves the gate, not a bad manifest. Layer api_version older than the app's is only a WARN (loader.c 4192).
