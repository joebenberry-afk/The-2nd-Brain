godot_assets fix round 1 (b01fffb, 2 Oct 2026): a licence_review counts only with text_sha256 = SHA-256 of the saved LICENSES/ file, and the stop message prints it. Poly Haven's licence is saved as the page's visible text, not its HTML, because the HTML changes with every site deploy and would stop every re-run. GitHub files are checked against the contents API's blob sha (git_sha1 = sha1(b'blob N\0'+data)); that API also works above 1 MB with the default Accept header (content empty, sha and size present). Unauthenticated GitHub allows 60 calls an hour: a fresh fetch of fonts and kaykit uses 16, a re-run with everything on disk uses 0.
