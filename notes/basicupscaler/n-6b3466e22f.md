Terraria is not usable as a sealed native LR/HR game via window resize: its fixed pixel scale changes the world view instead of render resolution (IDEAS CAP-13; DECISIONS 18c). Native 720p frames remain useful as unpaired probes; 100%/150% zoom pairing is only an untested idea (CAP-20). Sources: BasicUpscaler/IDEAS.md and BasicUpscaler/DECISIONS.md.
