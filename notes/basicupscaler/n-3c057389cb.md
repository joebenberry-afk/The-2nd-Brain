Godot 4.7.2 headless gotchas (godot-worlds Task 8): (1) the dummy renderer keeps no MultiMesh data: multimesh.buffer is empty and get_instance_transform returns identity, so HashingContext.update(empty) errors 'len == 0'. (2) unnamed add_child nodes get @Class@N names from a process-wide counter, so paths differ between two builds in one process. (3) a runtime error directly in a SceneTree script's _initialize aborts it before quit() and the headless run hangs forever; errors in callees only abort the callee and exit stays 0. Use OS.add_logger(Logger subclass counting _log_error) to fail on errors, and GDScript.can_instantiate() before .new().
