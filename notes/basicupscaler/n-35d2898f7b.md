Gotcha: Python-in-bash heredoc patch scripts turn \n escapes into real newlines and silently break replacements/f-strings. Write patch content with the Write/Edit tools, not heredoc string literals. Also: git bash python here writes LF with Path.write_text, safe for FORMULAS.md/IDEAS.md (LF files).
