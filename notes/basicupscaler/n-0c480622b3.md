Oh My Pi 18.8.6 facts (read from its source 8 Oct 2026): setting skills.customDirectories scans <dir>/<name>/SKILL.md and uses the real folder as skill dir; skills.enableClaudeUser=false here; Claude plugins are read only from the marketplace registry (installed_plugins.json), not skills-dir; ${CLAUDE_SKILL_DIR} is not expanded (OMP shows '[Skill directory: ...]' instead); 'omp read skill://<name>/<path>' is a free discovery check; agents live in ~/.omp/agent/agents with tools like web_search, read, grep, glob, find; 'omp -e <dir>' with no index.ts did not expose skills to 'omp read'.
