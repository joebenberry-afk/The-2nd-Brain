Scratch .mts/.ts scripts must be written with the write tool or a quoted heredoc (<<'EOF'), never <<EOF: an unquoted heredoc runs backtick contents as commands and expands $, so String.raw templates, regexes and paths arrive corrupted and node fails (ERR_INVALID_TYPESCRIPT_SYNTAX, triggerUncaughtException). Copy-and-patch source with the edit tool, not sed.
