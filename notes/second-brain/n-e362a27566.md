OMP bash in this repo has no TYPESAFE_API_KEY, so there is no paid pair judge: tidy prints "Similar (no judge)". That does not mean recall is lexical-only: recall can use the local Tora judge (recallJudge, brain/src/judge.ts). The deterministic lexical CLI tests (test/judge.test.ts, test/tidy.test.ts use fake judges) do not exercise the optional local or paid judges.
