Node mkdirSync(recursive) under /proc hangs forever; vitest looks stuck

A test that called mkdirSync with recursive:true on a /proc/... path spun a vitest worker at 100% CPU indefinitely. Use a path under a regular file to provoke a fast ENOTDIR instead.
