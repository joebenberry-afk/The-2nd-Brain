DSH memory is a Host plugin in dsh/, not an MCP server

Why: an MCP client row has one fixed cwd, but Harness sessions open arbitrary project directories, and the Brain resolves the project from cwd. dsh/index.js (bundle @local/dsh-second-brain) therefore spawns `brain` per call in the agent's working directory: the start card as one `agent/created` inbox message (source kind second-brain, form notice) and again after a `compaction/end` that dropped it; brain_recall, brain_note and brain_state as native tools; `brain fix` appended to a failed tool result by a tools/post-execute listener. Children get the tools but no card, and brain_state refuses them. Installed into the desktop profile with plugin_manager install_bundle; config: home (default SECOND_BRAIN_HOME), node, card, tools, fix. Delegating to the CLI keeps notes, judging and telemetry in one implementation; the cost is one Node process per call (about 0.3-0.7 s). Tests: node --test dsh/test/plugin.test.mjs (19 cases).
