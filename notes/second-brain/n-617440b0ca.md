Use OMP's /trace command to analyse sessions (time, tokens, cost, tool calls); the owner says it was really helpful before.
It serves a read-only dashboard and JSON API, seen at http://127.0.0.1:3847: /api/session/trace?file=<absolute session .jsonl path> (spans per track; summary of wall, model, tool and idle ms, turns, tool calls, subagents, tokens, cost, toolStats), /api/traces?range=24h, /api/stats/tools?range=7d, /api/stats/overview?range=7d.
/trace starts that dashboard on demand (@oh-my-pi/omp-stats startServer) and prints <dashboard>/#/traces?s=<session file>; `omp stats` serves the same dashboard (default --port 3847, --host 127.0.0.1); `omp stats --json` or `--summary` syncs all session files and prints once, without a server.
