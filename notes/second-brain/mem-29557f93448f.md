SQLite restore must never leave stale -wal/-shm beside the restored DB

Restoring db/brain.sqlite while a same-lineage -wal file remains replays stale frames (matching salts) and resurrects moved-aside rows. Restore must move the full DB file set aside, drop sidecars after the copy, and verify the restored sha256.
