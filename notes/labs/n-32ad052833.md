ECNG3006 FreeRTOS: course uses lib_deps briscoetech/FreeRTOS_SAMD21 @ ^2.3.0. Course PDF template overrides main(), which skips Arduino init()/USB setup so SerialUSB breaks; use library's way instead: create tasks + vTaskStartScheduler() in setup(), loop() = idle hook. Library tasks.c emits implicit-declaration warnings for runtime-stats funcs (harmless, library-internal).
