ECNG3006 FreeRTOS labs keep the course template's main() and repair USB serial by hand; lib_deps briscoetech/FreeRTOS_SAMD21 @ ^2.3.0 (Lab 2 Q2-Q4, lab1 Question 7).
Overriding main() skips the Arduino core's startup, so SerialUSB is dead until the board is brought up by hand. Each project does that in a small C++ file called first from main(): init(); __libc_init_array(); USBDevice.init(); USBDevice.attach(); (Lab 2/Q3, Q4 and Lab 3/Q2, Q3 src/serial.cpp; Lab 2/Q4_group_idle_hook/src/board.cpp, which sets pin directions after init() because init() resets pins). main() then creates the tasks and calls vTaskStartScheduler().
The labs do not use the library's setup()/loop() style. vApplicationIdleHook is defined only where the question asks for it (Lab 2/Q4, Q4_group_idle_hook).
