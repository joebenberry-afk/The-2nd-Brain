Anime Impact 2D art goes through Gemini, not Meshy: run `python tools/art/gen_image.py` from bash, because the eval Python kernel's environment lacks GEMINI_API_KEY.
- Default model `gemini-3.1-flash-image`. With `--transparent` it adds a magenta-background instruction to the prompt and keys it out.
- When a style-anchor reference is attached, the prompt must include "ONE creature only, not a character sheet, full body"; otherwise flash copies the anchor's multi-view layout.
- `gemini-3-pro-image` crops figures.
