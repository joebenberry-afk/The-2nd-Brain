Anime Impact turnaround procedure:
- Call `meshy_image_to_image` with ai_model nano-banana-2-1, `generate_multi_view: true`, `remove_background: true` (4 credits). Refs are canon wiki images, fetched through the fandom API with `prop=pageimages|imageinfo`. Original mobs use the Gemini JJK concept as the ref.
- `meshy_download_model` with `save_to=<dir>` writes `<dir>_0.png`… next to the dir.
- Inspect each set and name the views `turnaround_v1_{0 back,1 front,2 side}`. Meshy's output order varies, see the gotcha note.
- Store sets under `art/characters/{heroes,summons,bosses,mobs}/<id>/` and refs under `art/references/<kind>/<id>/`.
