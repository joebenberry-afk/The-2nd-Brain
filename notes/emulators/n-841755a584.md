XC2 NS2 (0400E95004038001) data layout for modding
Game data is in add-on Data title 0100E95004039062 (bf2.arh/bf2.ard + sound/*.pck), not the program RomFS (only dummy.bin). LayeredFS for it: load/0100E95004039062/<mod>/romfs (fsp OpenDataStorageByDataId → PatchRomFS Data). bf2.arh 'arh1': string/node tables XOR u32 with (hdr key ^ 0xF3F35353); file table <QIIII (off, cs, us, flags, id), each entry is an xbc1 (zlib, 48-byte header, hash at 0x10 not crc32/crc32c/xxh32/mmh3). common.bdat = entry 4565, path bdat/common.bdat; NS2 BDAT is the XC2 v1 format (flag 2 = names/strings scrambled with the 0x16 key), 926 tables, superset of Switch 1's 844, several tables have inserted rows, so match rows by content, not id. romfs_ext *.ips loads the whole target file in RAM (unusable on the 15 GB ard).
