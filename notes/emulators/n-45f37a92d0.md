Xenoblade Chronicles 2 Switch 2 Edition (.nup, 0400E95004038001) boots in-game on Eglantine fe-buf since 10945e3 (4 Orchid ports).
Four blockers, in order: (1) abort 2010-0011: 39-bit alias region 64 GiB, game reserves 60 GiB twice -> 128 GiB for Switch 2 (6a94249). (2) null call in NativeWindow::Acquire: gsv 1510 answered 8 KiB alignment -> 4 KiB (7d00779). (3) abort 2162-0001: game data is in the NUP's add-on packages, not mounted -> SetBootContent + aoc listing (8bd84eb). (4) scrambled colours/font: texture header word 2 bit 24 = Maxwell GOB layout (490b56b).
Still open: small thumbnail-like rectangles composited near the bottom of the frame; native upscaler network rejected (HMMA matrix multiply) and falls back to plain copy; first boot is black ~80 s (two compute pipelines, 38 s each in the driver).
Lab gotcha: a freshly copied eden-cli.exe stalls ~11 s right after opening the game file on its first launch or two (same for both titles, gone on later launches of the same file). Do not read that as load time when comparing builds.
Lab has no prod.keys, so NCA/NSP paths (Switch 1 titles) cannot be tested there; user must supply keys.
