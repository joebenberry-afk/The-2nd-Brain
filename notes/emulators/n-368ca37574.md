Eglantine repo: `git apply` under core.autocrlf=true rewrites touched worktree files as CRLF (tree convention is LF); eval `commit` namespace then sees whole-file diffs and would commit CRLF blobs.
Fix: apply patches with `git -c core.autocrlf=false apply ...`; repair with `xargs dos2unix -k -q < changed.txt` (git diff stays identical). Check with `git ls-files --eol <file>` (want i/lf w/lf).
