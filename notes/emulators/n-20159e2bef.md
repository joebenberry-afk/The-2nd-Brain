Eval kernel dies if a cell blocks in subprocess.run past the cell deadline (default is short): all kernel state is lost.
Always pass `timeout=` to subprocess.run and set the cell `timeout`; run slow tools (e.g. tools/check_accuracy_policy.py --all) via bash instead. Recovery that worked: `rows = await archive.sessions(silent=True)`, parse rows[0]["file"] JSONL, collect every dict with a "code" string, then ast-extract the last top-level def/assign per helper name (compile flags PyCF_ONLY_AST | PyCF_ALLOW_TOP_LEVEL_AWAIT) and exec. Main's ledger is now persisted to src/fe-lab/plans/ledger_main.json via save().
