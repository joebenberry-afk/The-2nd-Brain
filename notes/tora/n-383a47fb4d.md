Tora runs as a stdio MCP server only (owner 10 Oct): no always-on HTTP service and no autostart. It is registered in ~/.omp/agent/mcp.json with the venv's python.exe run directly. Don't use `uv run` for it, because uv checks the lock against PyPI at session start, and PyPI is ~30 KB/s here.
