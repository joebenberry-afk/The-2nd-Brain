An omp restart kills the live-queue runner (queue.py) and all subagents without a trace in proc://; the runner's done set is in memory only. Before restarting a queue: check `python -m tools.locks status` and D:\BU-gen\GameDriver\pending (both empty = safe), then remove completed items from queue.json (names in queue-results.json), rename queue-results.json to queue-results-partN.json, append a note to queue.log, and relaunch `python <queue dir>/queue.py`. Re-dispatch agents with their transcript (history://NAME) as context.
