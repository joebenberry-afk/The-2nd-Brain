A killed or crashed BU process leaves its real-time ETW session (BU_Timebase_<pid>_0) running with no consumer. Its buffers fill, so later EventWrite calls from the PCL test provider fail with Win32 error 8, and bu-win tests owned_emitter_reaches_native_etw_with_absolute_qpc and pcl_test disabled_by_default_and_wire_schema panic.
Fix: `logman query -ets`, check that the pid in the name is dead, then `logman stop BU_Timebase_<pid>_0 -ets`. Verified 14 Oct: 134/134 then passed.
