In the omp bash tool, `(python poller.py ... &)` inside a long async command dies silently (no output file), though the script works in the foreground. Start side processes for live probes from Python (subprocess.Popen with DETACHED_PROCESS) or a separate async bash job, and check the output file exists before the main run starts.
