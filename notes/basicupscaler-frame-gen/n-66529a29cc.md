omp bash tool cannot run an .exe whose /c/ path has spaces: `"/c/Program Files/NVIDIA Corporation/Nsight Systems 2026.5.1/target-windows-x64/nsys.exe" --version` → "error: command not found" although the file exists. Run such binaries from the eval kernel with subprocess.run([r"C:\Program Files\...\nsys.exe", ...]) or through `python -m tools.bench run -- <path>`.
