Plan an M1 cohort (`python -m arena.m1_gate plan`) only when no T15 session is running. While a session runs, T15 has the frozen settings block applied to the owner's settings files, so `settings_proof.validate` fails with "owner settings changed since proof; reacquire before freezing" and every step of that game gets planned as blocked. On 2026-10-15 cohort K2 (164852Z) lost all its Palworld steps this way, because its plan ran during Palworld's exit/restore. Check first: `python -m tools.locks status` shows no locks and `D:\BU-gen\GameDriver\pending` is empty.
