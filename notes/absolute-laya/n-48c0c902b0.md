Don't poll `python scripts/jobq.py status | grep -q ...` in a loop on Windows: grep -q closes the pipe early and jobq prints an OSError [Errno 22] traceback every iteration, flooding the output. Wait on a result file instead (e.g. `[ -f results/verdict-X.json ]`), or redirect jobq output into a variable first.
