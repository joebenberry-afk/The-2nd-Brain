Swarm loop for multi-file work: read-only reviewers per slice (only reproduced findings, file:line, max 10) → implementers with disjoint file ownership and shared contracts in the task context, scoped tests only → parent runs the full gate once, smoke-tests the real surface, commits → re-review the new commit.
Pitfall: `gate && … | grep …; git commit` commits on a failing gate (grep succeeds); write the gate to a log and test it before committing.
