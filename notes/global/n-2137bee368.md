Codex CLI 0.162.1 under a ChatGPT login: to send traffic through a local proxy, define a custom provider; OPENAI_BASE_URL is ignored.
-c openai_base_url=... does work, but Codex first retries a WebSocket for ~8 s ("Handshake not finished", 5 retries), then sends zstd-compressed bodies. features.responses_websockets=false does not stop this.
What works: -c model_provider=brain with model_providers.brain = { name, base_url="http://127.0.0.1:<port>/chatgpt/backend-api/codex", wire_api="responses", requires_openai_auth=true, supports_websockets=false }. This sends plain JSON to POST /backend-api/codex/responses. The Bearer token and chatgpt-account-id pass through. The full input is sent every request (no previous_response_id).
Claude Code 2.1.296: ANTHROPIC_BASE_URL=http://127.0.0.1:<port>/anthropic works with subscription OAuth.
