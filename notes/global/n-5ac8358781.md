OMP bash tool on this Windows box is a POSIX shell (Git-bash-like): cmd syntax like `dir /s /b X` runs Unix `dir` over the whole C: drive (218k lines). Use `find`/`ls` in bash, or `powershell -NoProfile -Command` for Windows-native queries.
