In `claude -p --output-format json`, `total_cost_usd` and `modelUsage` are the session's running totals across `--resume` calls; only `usage` is per call.
Summing `total_cost_usd` over the calls of a session overstates cost by 9–14× on bench runs: E6 default summed to $3.32, true $0.375; E2 d10 default summed to $1.02, true $0.076.
Use the last value, or each call's difference. probebench.ts was fixed on 2026-10-17.
Also: CC's list-price estimate per turn jumps about 4× once a turn's input passes ~177–192k tokens (claude-haiku-5-5). The reason is unverified.
