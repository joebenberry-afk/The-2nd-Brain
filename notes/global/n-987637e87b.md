When dynamically importing Python modules with dataclasses, register the module in sys.modules under its real __name__ before executing it: module = importlib.util.module_from_spec(spec); sys.modules[spec.name] = module; spec.loader.exec_module(module). Dataclasses resolve annotation types through that registry; an unregistered module can fail with NoneType.__dict__.
