Git Bash /c/... paths passed to native Windows tools (Python, PowerShell, Bun) are misread: Python resolves /c/Users/... to C:\c\Users\... (creates a stray C:\c tree), and Bun fails with `error: Module not found "/c/Users/...`. Always pass quoted drive-letter paths with forward slashes (C:/Users/...) to native Windows tools. Evidence (30 Sep): an agent then rm -r'd C:\c unchecked; never recursive-delete outside the workspace, and check what a path resolves to first.
