"CLM" (owner usage) = Context Language Model, Shao et al. arXiv:2609.37725: the model edits its own live context (a file synced back before each turn); RLM controls what is read in, CLM what stays.
In OMP it is buildable as an extension without forking or touching Bun: the documented `context` hook may return `{ messages }` to rewrite the list before every LLM call (omp://hooks.md, omp://skills/authoring-hooks.md), plus a registered tool for edit ops. The session file keeps full history.
