Windows venv: Scripts/python.exe is a launcher; the real interpreter is its child process. Killing the launcher's PID leaves the real python running (and holding files/locks, e.g. a GPU lock in BasicUpscaler 2026-10-01). Kill trees with taskkill /F /T /PID.
