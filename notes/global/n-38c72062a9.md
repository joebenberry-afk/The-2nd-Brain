DXGI Desktop Duplication / WGC capture the DWM *composited* surface, not scanout — so frames presented via independent/direct flip are invisible to capture. Measured: DLSS Frame Generation 310.x+ (RTX 40/50, driver 572.x+) inserts interpolated frames via hardware flip metering straight to scanout, so a DDA-based stream sees only real frames (~50% loss). Reports: github.com/LizardByte/Sunshine/issues/3621 (capture method field "Desktop Duplication API (Windows)"). Working community fix: set HKLM\SOFTWARE\Microsoft\Windows\Dwm OverlayTestMode=5 (disable MPO) + restart dwm, AND keep a 1x1 topmost layered click-through window alive to force Composed Flip: github.com/fernandoenzo/ForceComposedFlip. Costs ~1 frame of compositor latency on the host and can break VRR for video apps. True exclusive fullscreen (DWM off) cannot be captured at all by either API.
