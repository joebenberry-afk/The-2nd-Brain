OMP service tiers and cost (verified 2026-10-19).
- tier.openai priority on openai-codex bills 2.5x usage-equivalent. It ran 2026-10-07 to 10-16, mostly on subagents, and was about $3,059 of $3,194 OpenAI cost. Since 10-17 the setting is "scale", which Codex serves as default (1x).
- Codex rejects flex: "Unsupported service_tier: flex (invalid_request_error)", tested with gpt-6.1-sol.
- tier.anthropic priority sends speed:"fast", which is Opus 5.5 fast mode at 2x ($8/$40) and draws from usage credits on subscriptions. Sonnet/Haiku 5.5 reject it with 400. Opus got 429 "Usage credits are required for fast mode", and OMP retries without it, so there was no surcharge, only wasted round trips. Set to none 2026-10-19 so enabling credits cannot silently double Opus cost.
