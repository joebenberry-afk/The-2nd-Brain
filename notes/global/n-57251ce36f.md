Node ESM `import ... from "node:http"` costs ~16 ms per process: building the builtin's ESM facade runs http's lazy getters, which load undici.
On a hot path (every Claude Code hook loads brain/src/cli.ts and everything it imports), fetch it when needed with `process.getBuiltinModule("node:http")` (it is typed, and it is not a dynamic import). Keep `import type` for the types.
Measured on Node 26: proxy.ts marginal import cost went from 16.0 to 3.3 ms; hook median from 133–137 to 118–123 ms.
Guard: a cli.test.ts case checks `process.moduleLoadList.includes("NativeModule http")` after importing cli.ts.
