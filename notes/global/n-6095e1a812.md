Codex on Windows: `codex exec --ignore-user-config` also drops `[windows] sandbox = "unelevated"`, so even `-s workspace-write` runs read-only and every shell command is rejected.
Fix: pass `-c windows.sandbox="unelevated"` explicitly next to --ignore-user-config. Verified codex-cli 0.162.1 on 2026-10-17 (probebench.ts).
Trap: a run whose tool calls were all rejected can still answer probes "correctly" from its own description of the edit, so benches must check the side effect (file really changed) before scoring.
