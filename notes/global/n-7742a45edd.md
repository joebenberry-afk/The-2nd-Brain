Windows ESM: importing an absolute path like "C:/Users/..." fails with ERR_UNSUPPORTED_ESM_URL_SCHEME
Use a relative specifier or a file:///C:/... URL (pathToFileURL(p).href for dynamic import). Seen 59 times in 8 days, mostly scratch .mjs/.ts scripts importing brain/src by absolute path; rewriting the specifier to file:/// fixed it every time.
