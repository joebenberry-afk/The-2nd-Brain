Python http.client: response.read(amt) returns a short body without IncompleteRead when the server closes early (client.py says so), and TLS ragged EOFs are suppressed by default, so a truncated HTTPS download can pass silently. Verify against a publisher size/checksum or the Content-Length header. Also: printing emoji on a Windows cp1252 console raises UnicodeEncodeError; set PYTHONIOENCODING=utf-8.
