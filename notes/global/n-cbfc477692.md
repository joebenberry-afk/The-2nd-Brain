OMP: a user interjection while an eval cell blocks in wait([...agents]) kills the kernel (exit 130) and cancels every agent that cell spawned; all kernel variables are lost.
For long jobs (builds, measurement runs) dispatch with the `task` tool instead (survives interjections, results auto-deliver) and have each agent write its full report to a file and return a short digest. Save kernel results to disk right after each wait.
