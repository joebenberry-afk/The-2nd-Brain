Claude Code Bash: an inline python heredoc with quotes fails with 'unexpected EOF while looking for matching'

The Bash tool runs the command through bash -c, so quotes inside a heredoc body (''' strings, apostrophes) break the outer quoting. Write the script to a scratch .py file with the Write tool and run python <file>; in the event logs that is the step that worked every time (74 failures in 14 days).
