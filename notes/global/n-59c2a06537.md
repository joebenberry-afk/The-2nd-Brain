OMP 18.6.1 mounts MCP and discoverable tools under xd:// (route line only, no schema); on 2026-10-05 the top-level schemas were 15 tools ≈ 3.7k tokens, all called within 14 days
The older ~4.8k figure for 11 unused mcp__jev_* schemas (n-aed96987dd) no longer applies. `brain stats` prints a `tool schemas` line, filled in by the OMP extension on each main session's first prompt. Extension getActiveTools() returns the enabled list including xd:// mounts, so tools named as xd:// routes in the system prompt are left out.
