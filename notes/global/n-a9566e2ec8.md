omp commit namespace stores CRLF worktree bytes raw (ignores core.autocrlf)
In Emulators/src/Eglantine-* (autocrlf=true) files created/rewritten by the write tool are CRLF in the worktree while HEAD blobs are LF. commit.draft() then shows the whole file as changed ("+193 −190, left out: unrecorded") and commit() writes a CRLF blob (362-line diff for an 8-line change). Check `git ls-files --eol <files>` for `w/crlf` before committing; convert those files to LF bytes first (write tool re-adds CRLF even for a new file), then verify `git cat-file -p HEAD:<path>` has no CR. amend=True repairs a bad commit.
