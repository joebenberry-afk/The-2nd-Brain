Windows: python -I ignores PYTHONIOENCODING -> UnicodeEncodeError on cp1252 stdout; use sys.stdout.reconfigure(encoding='utf-8'). Also shutil.rmtree(ignore_errors=True) silently leaves read-only git objects; use onexc=lambda f,p,_:(os.chmod(p,stat.S_IWRITE),f(p)).
