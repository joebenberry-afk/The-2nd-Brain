Multi-connection downloads for Zen (default browser, Firefox 157 base; Zen asks where to save each file): aria2 1.37.0 (winget, %LOCALAPPDATA%\Microsoft\WinGet\Links\aria2c.exe) runs as RPC daemon on 127.0.0.1:6800 with config %LOCALAPPDATA%\aria2-rpc\aria2.conf (16 conns, secret inside, session+log in same dir), started at logon by Startup-folder shortcut "aria2 download engine.lnk" -> conhost.exe --headless (no window, no admin needed). Browser side: AMO add-on "Aria2 Integration" (baptistecdr, slug aria2-extension); in Firefox it cancels the browser download BEFORE calling aria2, so if the daemon is down the download is lost. It forwards Referer+Cookie, not User-Agent (UA set in aria2.conf). Kept config out of %USERPROFILE%\.aria2 so plain aria2c CLI runs don't try to bind 6800. Measured via daemon: 1 conn 0.2 Mbps vs 16 conns 2.4 Mbps (VS Code installer, ~23:00).
