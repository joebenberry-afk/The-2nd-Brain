PMX study gotchas: measure_pmx.weld returns GLOBAL cluster ids — rep arrays sized W.max()+1 have zero rows for unused ids, so take min/max over P[np.unique(faces)], not rep. Lip slits are closed at rest so welding seals them; measure mouth width from the 'a' viseme band at the mouth line instead. Finger ring vert count: plane cross-section loop, not radius gather (radius catches neighbours, gave 22-31 vs true 8-12).
