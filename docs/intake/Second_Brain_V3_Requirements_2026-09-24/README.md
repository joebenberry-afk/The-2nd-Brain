# Second Brain V3 requirements bundle

Prepared 24 September 2026. This is a requirements/research package, not modified repository code or deployment evidence.

- `V3_FINAL_REQUIREMENTS.md`: final adoption proposal with 52 core requirements, acceptance clauses, six required comparisons, delivery slices and source provenance.
- `ACCEPTANCE_MATRIX.json`: the same requirement register plus 18 Given/When/Then acceptance scenarios, all explicitly unassessed/unrun.
- `RESEARCH_DECISIONS.md`: recent research and current component decisions, with limitations and the distinction between new September papers and established releases.
- `START_V3.md`: bounded first implementation direction; no cloud/issuer/orchestration detour.

Read the main document for normative requirements. Source IDs S01–S17 are resolved there. The JSON cases are a test plan, not an executable harness. Preserve requirement IDs when adding evidence.
