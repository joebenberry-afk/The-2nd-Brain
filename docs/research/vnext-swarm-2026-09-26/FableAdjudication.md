## 3. Experiment ladder (agent under test: `openai-codex/gpt-5.5`, effort medium, OMP pinned; report L, uncached/cached/output split, requests, tool calls, p50/p95 wall; no USD)

**Stage 0 — no model (after S0).** Re-grade frozen runs; freeze corpus + capsules + rubric; replay 100 labelled boundaries through the S3 matcher. Kill: <15/21 verdicts flip → grader still broken, stop.

**Stage 1 — oracle screen (parent's pilot = 1a).** Tasks M02/M04–M10 + 6 negatives, 2 reps. Arms: **N** native · **O-prompt** hand-chosen sufficient capsule with anchor as hidden prompt-time message · **O-adv** same capsule, "advisory, verify" framing · **O-static** same capsule placed in the user-level file. Pass to Stage 2 if O-prompt ≥ N on semantic correctness and geometric L ratio ≤0.7 on ≥5/8 hunt tasks; O-adv vs O-prompt settles framing (my finding 9); O-static vs O-prompt decides whether P-class knowledge may ever live in L1 (expect no). Kill: O-prompt shows no L or tool-call reduction on any hunt task → content is not the bottleneck; go back to S1.

**Stage 2 — mechanism (24 runs/arm, dev tasks only).** **S** = S3 selector picks from frozen corpus (O−S = selection loss) · **T** = O's capsule delayed to first matching tool result (O−T = timing loss, expected large per EvidenceMiner) · **H** = N + L1 block only on 6 negatives + 6 host-op tasks (FieldTelemetry classes) — pass if negatives ≤ +2% L / +0.5 steps and host-op first-call validity ↑. Kill L1 if negatives exceed margin (AGENTS.md-study risk).

**Stage 3 — confirmation.** 24 fresh tasks (6 families × 4, ≥3 repos incl. one unregistered) × 3 reps N vs vNext (L1+L2+L3+L4 on), + 12 fresh negatives × 2. Predeclared: mean log ratio CI excludes 1 and point ≤0.7; correctness non-inferior on adjudicated set; zero privacy/scope breaches; negatives within margin. Transfer check on `gpt-6-astra` only after a pass.

## 5. Top risks and tripwires

1. **Instruction-file tax (the AGENTS.md study).** Tripwire: Stage 2 H arm or any later negative set shows >+2% L or >+0.5 steps, or field telemetry shows no drop in the 5 seeded error classes over 2 weeks → cut L1 to the pull line only.
2. **L2 never fires or fires wrong** (thin corpus, poor `terms`, unregistered workspaces). Tripwire: field prompt-match rate <2% of prompts *and* Stage-2 S-arm precision <0.9 → revert to L4-only and fix capture before re-enabling.
3. **Capture stays at zero, so the corpus never grows past today's 6 deliverable items.** Tripwire: <3 accepted P/E capsules per week of real use after S7, or deliveries/week = 0 in `telemetry/kb-hooks.jsonl` → the product is a curated cheat-sheet, not a memory; decide whether to keep only L1+L4.
